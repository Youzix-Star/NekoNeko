# 图标资源文件

由于这是一个简单的示例项目，图标资源文件需要您自行创建。

## 需要创建的文件：

1. `ic_launcher.png` - 应用主图标 (72x72像素)
2. `ic_launcher_round.png` - 圆形应用图标 (72x72像素)

## 图标设计建议：

- 使用简洁的猫爪或猫脸图案
- 颜色方案：粉色 (#FF4081) 或橙色 (#FF5722)
- 确保图标在深色和浅色背景下都清晰可见

## 临时解决方案：

您可以暂时使用Android默认图标，或者从网上下载免费的猫图标。

## 在Android Studio中：

1. 右键点击 `res` 目录
2. 选择 `New > Image Asset`
3. 选择图标类型和配置
